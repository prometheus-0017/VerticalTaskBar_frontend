# DoorTaskBar — 开源垂直任务栏

## 动机

Windows 11 原生任务栏长期不支持垂直布局（听说近期在测试通道中做了，但是需要加入预览计划并登录微软账户，体验也一言难尽）。

DoorTaskBar 的初衷很简单：**做一个以效率为主的任务栏,而不是为了好看不要功能的银样镴枪头。**

## 用途

DoorTaskBar 是一个运行在 Windows 上的**外挂式垂直任务栏**，以侧边栏的形式列出当前所有打开的窗口，并按"分组"组织。它可以替代或补充系统任务栏，用于：

- **多主题/多项目工作流**：为每个项目创建独立分组，互不干扰
- **窗口快速切换**：点击条目即可弹出对应窗口，支持拖拽文件到条目触发弹出
- **窗口标题重命名**：覆盖原始标题，在大量相似窗口中快速区分
- **局域网远程管理**：通过手机或其他设备浏览器访问，获得一个小分屏任务栏
- **浏览器标签页合并管理**（测试阶段）：通过浏览器插件将标签页纳入任务栏统一管理

## 特点

| 特点 | 说明 |
|------|------|
| **垂直布局** | 一个窗口条目可以展示更长的文本标题 |
| **分组管理** | 每个主题拥有独立的任务栏和独立的搜索框 |
| **稳定** | 独立进程，微软任务栏崩溃不影响本工具 |
| **安全** | 低权限外挂式程序，不改注册表，不要求管理员（当然管理员权限可支持更多功能） |
| **开源** | 前后端代码完全开源，可自行扩展 |
| **窗口标题覆盖** | 可对任意窗口重命名，仅影响侧边栏显示 |
| **自动/手动收录** | 新窗口可自动追加到当前分组，或仅进入 main 分组等待手动拖拽 |
| **主题切换** | 支持亮色 / 暗色 / 跟随系统三种模式 |
| **状态持久化** | 可保存当前布局和配置，崩溃重启后一键还原 |
| **局域网访问** | 开启远程后，局域网内任意设备可通过浏览器访问任务栏 |
| **WebView2 内核** | 基于系统自带的 Edge Chromium，无需额外安装浏览器 |

## 使用方法

### 使用

运行 main.exe

### 构建

#### 前置条件

- Windows 10 / 11
- Python 3.12+（后端）
- Node.js 18+ 及 pnpm（前端开发）
- 系统已安装 WebView2 运行时（Windows 11 自带）

#### 前端构建(frontend项目)

```bash
pnpm install
pnpm run build    # 产物输出到 frontend/dist/
```

#### 后端运行（backend项目)

复制文件 frontend/dist 到 backend/dist

```bash
pip install -r requirements.txt
python main.py
```

### 界面功能说明

启动后，屏幕左侧会出现一个垂直侧边栏。顶部是一排功能按钮，下方是分组标签栏、搜索框和窗口列表。

#### 顶部按钮栏（从左到右）

| 按钮 | 文字 | 功能 |
|------|------|------|
| `<` | 收回 | 手动收起任务栏，鼠标移到屏幕左上角可重新弹出 |
| `刷` | 刷新 | 刷新页面（重新加载前端 UI） |
| `定`/`动` | 固定 | 切换鼠标移出后是否自动收起。`定`=不自动收起，`动`=自动收起 |
| `远`/`关` | 远程 | 切换是否允许局域网远程访问。`远`=允许，`关`=仅本机 |
| `共`/`单` | 搜索模式 | `共`=所有分组共用同一个搜索框内容，`单`=每个分组独立搜索框 |
| `修`/`留` | 修剪空格 | `修`=搜索时去掉关键词首尾空格，`留`=保留 |
| `日`/`夜`/`随` | 主题 | 循环切换：亮色 → 暗色 → 跟随系统 |
| `追`/`无` | 追加模式 | `追`=新窗口自动追加到当前查看的分组，`无`=新窗口仅进入 main 分组 |
| `存` | 保存 | 保存当前布局、配置到 `status.json`，崩溃重启后可还原 |
| `x` | 退出 | 退出程序 |

#### 分组标签栏

- 点击 `+` 创建新分组（弹出输入框填写名称）
- 点击分组标签切换到该分组
- **F2**：对当前选中的分组重命名 / 编辑捕获条件（弹出编辑窗口，可设置名称和自动捕获规则(规则尚在测试)）
- **Ctrl+W**：删除当前分组（main 分组不可删除）
- 分组标签支持**拖拽排序**

#### 搜索框

- 输入关键词过滤当前分组的窗口列表
- 搜索匹配窗口标题（优先使用修改后的名称）和进程名
- 点击右侧 `×` 清除搜索内容

#### 窗口列表

- **左键单击**条目：弹出（切换到）对应窗口
- **右键单击**条目：重命名该窗口标题（仅影响本工具的显示）
- **Shift + 右键单击**条目：删除该条目之后的所有条目（非 main 分组）
- **拖拽文件**到条目上：触发弹出对应窗口（你无法将一个文件拖拽到win11 的任务栏的溢出栏里,但是本工具没有溢出栏这种东西）
- 非 main 分组中，鼠标悬停时条目右侧出现 `x` 按钮，点击可删除该条目
- 条目支持**拖拽排序**（在同一个分组内）
- 条目支持**拖拽到其他分组标签**上，复制到目标分组

#### 分组编辑弹窗(beta)

按 F2 选中分组后弹出，可配置：
- **名称**：分组显示名称
- **捕获条件列表**：每条规则包含类型（`pwd` / `name` / `originName`）和匹配值。新窗口满足任一条件时自动加入该分组

## 当前问题与待办

### 已知问题

1. **前后台连接断开**：WebSocket 连接可能意外断开，临时解决方案是先保存布局再刷新页面
2. **奇怪窗口未过滤**：部分系统弹窗或隐藏窗口可能出现在列表中,但是问题不大
3. **高权限窗口兼容**：如果本程序以普通用户权限启动，对管理员权限窗口的操作可能受限（图标显示异常、无法弹出）

### 待办

- [ ] 完善窗口自动过滤规则
- [ ] 解决前后端连接断开的根本问题
- [ ] 改进浏览器标签页集成体验
- [ ] 窗口图标准确性优化（高 DPI 适配）
- [ ] 捕获条件的远程匹配（当前远程模式下 modify 类条件可能不生效）
